# Bella & Edward - Wedding Invitation 🕊️

Welcome to the digital wedding invitation of Bella & Edward. This project is a classic, fine-art style web invitation featuring interactive elements, smooth scrolling animations, and an integrated RSVP form. 

### Features
- **Interactive Envelope:** A CSS-based realistic envelope that opens upon clicking, revealing the main website.
- **Autoplay Music:** A delicate music button integrated into the hero section with background audio ("Turning Page").
- **Dynamic Countdown:** A custom countdown timer counting down the days to the ceremony.
- **Responsive Design:** Fully responsive layout ensuring a perfect viewing experience on both desktop and mobile devices.
- **Built with:** HTML5, CSS3, JavaScript (Vanilla), and AOS (Animate on Scroll).

# Convite de Casamento - Bella & Edward 🕊️

Bem-vindo ao convite de casamento digital de Bella & Edward. Este projeto é um convite web com estilo clássico e *fine-art*, que traz elementos interativos, animações suaves e um formulário de RSVP integrado.

### Funcionalidades
- **Envelope Interativo:** Um envelope realista construído em CSS que se abre ao clicar, revelando o site principal.
- **Música Automática:** Um botão de música delicado integrado com áudio de fundo ("Turning Page").
- **Contagem Regressiva Dinâmica:** Um cronômetro customizado contando os dias até a cerimônia.
- **Design Responsivo:** Layout totalmente adaptável para garantir uma experiência perfeita tanto no computador quanto no celular.
- **Construído com:** HTML5, CSS3, JavaScript (Vanilla) e AOS (Animate on Scroll).
